# 2048 — Dobrze się składa

Kompletna gra 2048 po polsku, bez zależności i bez potrzeby instalacji.

## Uruchomienie

Otwórz plik `index.html` w przeglądarce. Możesz też uruchomić lokalny serwer, np. `python3 -m http.server 8000`, a potem wejść na `http://localhost:8000`.

Sterowanie: strzałki, WASD, przyciski kierunkowe lub przesunięcie palcem po planszy. Przycisk **Nowa gra** resetuje partię. Rekord jest zapisywany lokalnie w przeglądarce.

## Testy logiki

Jeśli masz Node.js, uruchom `node --test game-logic.test.js`.
